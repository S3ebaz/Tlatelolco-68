# Tlatelolco 1968

Página conmemorativa del movimiento estudiantil y de la masacre en la Plaza de las Tres Culturas. Línea de tiempo del 22 de julio al fin del movimiento, con el 2 de octubre hora por hora. Funciona sin conexión después de la primera visita.

## Archivos

| Archivo | Qué es |
|---------|--------|
| `index.html` | Línea de tiempo del 68 |
| `ahora.html` | Página de contexto |
| `sw.js` | Service worker (sin red después de la primera visita) |
| `manifest.webmanifest` | Datos para abrir como app |
| `.gitignore` | Ignora ZIP y archivos basura |

## Publicar

1. Repo **público**.
2. Archivos en la **raíz**.
3. Settings → Pages → `main` / `(root)` → Save.
